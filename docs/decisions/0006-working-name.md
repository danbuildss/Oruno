# 0006 — Oruno is a working name

**Status:** Accepted · **Date:** 2026-10-30

**Context.** Name candidates were reviewed; Wayline, Openway and Relay conflict with existing companies. Oruno had no conflicts in a quick search. Positioning is locked: "Intelligence should move freely."

**Decision.** Use Oruno as the working name until after Drop #1. Before public use, check trademarks, domains, the GitHub org and the npm scope.

**Consequences.** Names in code and docs may change; avoid hard-coding the brand where it's easy not to.
