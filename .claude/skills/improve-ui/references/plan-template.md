# Plan template

Copy this into `design-plans/NNN-short-name.md`. The executor has no context beyond this file.

```markdown
# <NNN> — <One-line change>

- **Status:** PROPOSED | APPROVED | DONE | STALE
- **Written against commit:** <short hash>
- **Finding:** <the problem, in one sentence>

## Why
<The binding rule (cite file and section) and how the problem reaches people (cite file:line).>

## Change
<The one correction. Exact files, lines, and old → new values. Reuse existing tokens/variants by name.>

## Do not change
<Nearby things that must stay as they are, and why.>

## Affected surfaces
<Every page or state where the result is visible.>

## Verify
<Commands to run and what must be true afterwards, including any test or screenshot to check.>

## Docs to update
<Accepted documentation changes, or "None".>
```
